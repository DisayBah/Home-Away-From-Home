HOME AWAY FROM HOME — VS CODE PROJECT

FILES
- index.html: homepage
- apartments.html: sample accommodation listings
- facilities.html: facilities information
- about.html: project/about page
- contact.html: demonstration contact form
- css/style.css: design, typography, spacing and responsive layout
- js/script.js: mobile navigation, footer year and demo form interaction
- images/logo.svg: website logo

HOW TO OPEN IN VISUAL STUDIO CODE
1. Extract this ZIP file.
2. Open Visual Studio Code.
3. Choose File > Open Folder, then select the extracted home-away-from-home-vscode folder.
4. Open index.html.
5. If you have the Live Server extension, right-click index.html and choose "Open with Live Server". Otherwise, open index.html in your browser.

NOTES
- The accommodation listings are sample concepts for a school project, not real or verified rental offers.
- The photographs load from Unsplash, so an internet connection is required to display them.
- The contact form is a front-end demonstration only; it does not send or save messages.
- To change text, edit the relevant HTML file. To change colours, spacing or typography, edit css/style.css.
